## 대상 설정

- 전체 범위 입력 예시: infra/gcp/ghost-project.tfvars.example.
- 독립된 상태 버킷 후보: ghost-project-513812-tfstate.
- 플랫폼 상태 경로 후보: gcp/dev/platform.
- 리전: 기존 AWS 서울에 대응하는 asia-northeast3.
- 이전 프로젝트의 상태·결제/API 관찰을 새 프로젝트의 증거로 사용하지 않습니다.

로컬 상태 저장소 설정 후보는 Git에서 제외된 backend.local.hcl 및 bootstrap/ghost-project.local.tfvars에 준비했습니다. 예시 입력의 도메인·알림 이메일·접근 허용 주소·Tailscale 비밀 참조는 여전히 비어 있으므로 전체 구성 계획을 실행할 준비가 완료된 것은 아닙니다.

1. 명시적 승인 후 Google 공식 명령줄 도구의 로그인만 완료합니다. 서비스 계정 키 파일은 생성하지 않습니다.
2. 명령마다 ghost-project-513812를 지정하여 읽기 전용 사전 조회를 실행합니다.
3. 기존 상태·자원과 할당량을 확인한 뒤 상태 저장 버킷의 생성 계획을 검토합니다.
4. 나머지 실제 입력을 채우고 전체 자원의 생성·변경·삭제 계획과 예상 비용을 검토합니다.
5. 배포 후 자원별 상태, 사설 통신, 시크릿 동기화, 로그와 알림을 확인하여 체크리스트를 갱신합니다.
